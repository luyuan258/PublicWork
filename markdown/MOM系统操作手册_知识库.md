# MOM系统操作手册（版本9.1）

> **来源：** MOM系统操作手册V9.1.docx
> **系统全称：** 墨迅MOM系统（Manufacturing Operations Management）
> **子系统：** WMS（仓储管理）、MRO（设备管理）、质量管理、生产管理

---

## 一、系统概述

### 1.1 系统整体业务流程范围

本次墨迅MOM项目包括以下组成部分：

- **软件部分：** 本系统是根据墨迅的实际情况、管理需求，经过个性化开发的应用系统，包括：基础数据、权限管理、生产管理、仓库管理、质量管理
- **系统接口：** WMS系统和ERP系统的接口、WMS与WCS互联

### 1.2 系统登录

- **内网地址：** `http://172.16.11.17:8660`
- **外网地址：** `http://58.214.16.2:8660`

> 登录界面说明：Chrome浏览器打开后，左侧为蓝色渐变科技感插画，右侧为白色登录面板，含"星联脉斯"品牌标识和"用户登录"表单，输入账号密码后点击登录进入系统。登录后首页为全景导航界面，左侧垂直菜单栏包含系统设置、基础设置、生产管理、仓储管理、报表看板等功能模块，右侧主区域以卡片布局展示各子功能入口。

## 二、WMS采购业务操作流程

### 2.1 流程总览

```
ERP采购订单 -> WMS采购模块 / 供应商平台 -> 到货/送货 -> 质量来料检验 -> 合格入库 / 不合格退货
```

### 2.2 接收ERP采购订单

在ERP采购模块创建采购订单，下发至WMS系统的采购模块以及供应商平台。

#### 2.2.1 内部采购订单

> 界面功能：MOM系统左侧导航栏（系统设置、基础设置、生产管理、采购管理等模块），主区域为采购订单数据列表，支持查询、新增、编辑等操作。顶部蓝色条栏显示"江苏墨迅"和当前用户信息。

#### 2.2.2 供应商平台采购订单

> 界面功能：供应商平台下"送货管理"模块中"采购订单"功能高亮显示，右侧为采购订单详细信息，含物料信息、供应商、数量等具体数据。操作按钮包括返回、刷新、新增、弃审等。

### 2.3 内部采购到货或供应商平台送货

#### 2.3.1 内部采购到货

**步骤1：参照采购订单**
- PC端选择"到货单"模块，点击"采购订单明细"按钮
- 输入ERP采购订单号，勾选到货物料明细行，点击确定，生成到货单

> 界面功能：采购到货列表页面，操作按钮包括新增、采购订单明细、生成条码、审核、打印到货单、条码打印、生成来料检验任务单、数量更新等。查询条件含到货单号、采购订单、ERP采购订单号、供应商编码等。数据表格列出到货单号（SL2026XXX格式）、单据日期、状态（开立/已到货）、关联采购订单、供应商等信息。

**步骤2：条码生成及打印**
- 输入到货数量后，点击"生成条码"按钮，根据明细行信息生成条码
- 点击"打印到货单"和"条码打印"，分别将到货单和物料条码打印出来，并与实物绑定
- PDA提交后到货单会自动审核，状态改成"已到货"

> 条码打印格式：到货单标题下含ERP单号、送货单号、供应商、业务类型、送货日期、二维码，以及物料明细表（物料编码、名称、规格型号、数量、包装规格、批号）。

**步骤3：到货验货及检验任务生成**
- PDA上选择"到货检验"功能，扫描送货单条码，再扫描实物条码
- 根据送货单以及扫描的条码信息进行校验，查看物料以及数量信息是否一致

> PDA功能菜单：网格布局16个功能模块，包括叫料、拆垛码、条码查询、销售退货、其他入库、取样拆码、材料出库、到货检验（高亮）、采购入库、来料上架、采购退货、备料拣货、仓库调拨、调拨接收、库位调整、取样出库。

- PDA到货检验后根据到货单明细行物料以及对应的检验策略自动生成"待检"状态的检验任务单

#### 2.3.2 供应商采购送货

**步骤1：参照采购订单**
- 供应商平台选择"采购送货单"模块，点击"采购订单明细"按钮
- 输入ERP采购订单号，勾选送货物料明细行，点击确定，生成采购送货单

> 界面功能：采购送货单列表页面，左侧菜单展开"送货管理">"采购送货单"，查询弹窗支持按ERP采购订单号筛选。来源数据对话框展示采购订单明细列表（ERP单号、采购订单号、单据日期、供应商、物料编码、规格型号、订单数量、剩余数量），可勾选确认。

**步骤2：条码生成及打印**
- 输入送货数量后，点击"生成条码"按钮，根据明细行信息生成条码
- 审核后生成到货单，点击"打印送货单"和"条码打印"，分别将送货单和物料条码打印出来，并与实物绑定

> 送货单详情（如SL202403200001）：显示送货单号、单据日期、状态"已到货"、供应商信息、关联采购订单号（如PO20240320001/PO202403200002），明细含物料编码/名称、批号、送货数量、到货数量、接收数量。操作按钮含打印送货单、参照采购订单、条码打印等。

**步骤3：到货验货及检验任务生成**
- PDA上选择"到货检验"功能，扫描送货单条码，再扫描实物条码
- 根据送货单以及扫描的条码信息进行校验，查看物料以及数量信息是否一致
- PDA到货检验后根据送货单明细行物料以及对应的检验策略自动生成"待检"状态的检验任务单
- 当该物料没有建立检验策略时，生成一张无检验策略的空白检验任务单，后续质检人员需增加该物料的检验策略以及填写检验任务单

### 2.4 质量来料检验

#### 2.4.1 质量取样

- 质量人员收到待检状态的检验任务单
- 通过PDA"取样拆码"功能，扫描实物条码，输入取样数量
- 从原条码中拆出取样条码，供后续检验使用
- 拆码取样时若无检验策略则保存失败

> PDA取样拆码界面：显示来料检验任务单、原条码、物料档案、批次、数量、取样数量等字段，带条码扫描图标。拆码后生成条码主档记录（如物料M510017离合器，批号202403200001，分拆为数量5和95两个条码）。

#### 2.4.2 填写检验记录单

- 质量人员检验完成后，在PC端 **质量管理->执行->检验记录单** 模块
- 点击新增，选择取样条码，输入检验数据

> 检验记录单界面：上方显示选择条码、批次号、零件名、数量、送货日期等信息区，下方表格列出检验项目、检验标准、公差、特性、方法/工具及各测量数据列。列表视图展示已审核状态的检验记录（含零件名PCBA、零件号、批次号、抽检数量、送货数量、检验时间）。

#### 2.4.3 生成检验处理单

检验记录单审核后生成检验处理单。处理方式包括：
- 让步接收
- 报废
- 退回
- 挑选（需填写良品数量与不良品数量，处理单审核时根据良品数量及包装规格重新生成良品条码，供后续PDA扫码入库）

### 2.5 来料不良处理

#### 2.5.1 采购到货拒收

原材料到货但还未入库时，若检测到不良，需进行拒收处理：
- 点击"新增"按钮，选择到货单明细+拒收条码，输入拒收数量
- 提交后生成拒收单并更新采购订单拒收数量

#### 2.5.2 采购退货

原材料已入库后检测到不良时：
1. **参照采购订单：** PC端 **仓储管理->采购->采购退货** 模块，点击"参照采购入库单"，选择需退货的采购入库单，输入退货数量
2. **扫码退货：** 打印采购退货单，PDA选择"采购退货"功能，扫描采购退货单及退货实物条码，完成后系统生成采购入库单（红字）
3. **回传U9：** 在 **仓储管理->入库->采购入库单（红字）** 模块，选择对应单据，点击"插入U9"

### 2.6 采购入库

#### 2.6.1 实物扫码到分拨墙暂存区

PDA选择"采购入库"功能，扫描采购到货单或采购送货单，再扫描条码以及库位，生成采购入库单。

#### 2.6.2 发送WCS调用AGV小车

若所扫描的库位是分拨墙暂存区，则WMS会再生成一张库位调整单，发送至WCS，调用AGV小车进行材料搬运，完成后回写实物存放的库位。

#### 2.6.3 MOM-U9中间表

审核后系统会自动插入U9中间表，5分钟后自动同步U9。异常情况可以点击"插入U9"按钮。

## 三、WMS委外业务操作流程

### 3.1 流程总览

```
ERP委外订单 -> 委外发料 -> 供应商加工 -> 委外到货 -> 质量检验 -> 委外入库 / 退货
```

### 3.2 接收ERP订单

在ERP委外模块创建委外订单，下发至WMS系统的委外模块以及供应商平台。

#### 3.2.1 内部委外订单
#### 3.2.2 供应商平台委外订单

### 3.3 委外发料

#### 3.3.1 ERP调拨申请单

ERP库存模块根据委外订单用料情况，录入调拨申请单，并下发WMS。

#### 3.3.2 WMS委外发料

WMS接收ERP调拨申请单，仓库人员接收调拨信息后，判断是否需要AGV送料。

**AGV运料方式：**
- 在WMS **仓储管理->仓储作业->调拨申请单** 模块，选择调拨申请单
- 点击"生成货位调整单"按钮，自动生成需运料的货位调整单给WCS
- 调用AGV小车将所需的料从原料仓库位运送到分拨墙
- 后续仓库人员手持PDA扫描调拨申请单，再扫描实物条码及对应委外仓库位
- 完成后生成调拨单，并回传U9

**手工运料方式：**
- 仓库人员手持PDA扫描调拨申请单，再扫描实物条码及对应委外仓库位
- 完成后生成调拨单，并回传U9

### 3.4 内部委外到货或供应商平台送货

#### 3.4.1 内部委外到货

- PC端选择 **仓储管理->委外->委外到货** 模块，点击"委外订单明细"按钮
- 输入ERP委外订单号，勾选到货物料明细行，点击确定，生成委外到货单
- 输入到货数量后，点击"生成条码"按钮，打印委外到货单和物料条码，与实物绑定
- PDA提交后到货单自动审核，状态改成"已到货"
- PDA"到货检验"功能校验后自动生成"待检"状态检验任务单

#### 3.4.2 供应商委外送货

- 供应商平台选择"委外送货单"模块，点击"委外订单明细"按钮
- 输入ERP委外订单号，勾选送货物料明细行，生成委外送货单
- 生成条码、打印、审核、到货检验流程同上

### 3.5 质量委外检验

与来料检验相同：
1. **质量取样：** PDA"取样拆码"功能，扫描实物条码，拆出取样条码
2. **填写检验记录单：** PC端 **质量管理->执行->检验记录单** 模块，选择取样条码，输入检验数据
3. **生成检验处理单：** 审核后生成，支持让步接收、报废、退回、挑选等处理方式

### 3.6 委外入库

- PDA选择"委外入库"功能，扫描委外到货单或委外送货单，再扫描条码及库位，生成委外入库单
- 若扫描库位是分拨墙暂存区，生成库位调整单发送至WCS调用AGV搬运
- 审核后自动插入U9中间表，5分钟后自动同步U9

### 3.7 委外退货处理

1. **参照委外订单：** PC端 **仓储管理->委外->委外退货** 模块，点击"委外入库"，选择需退货的委外订单，输入退货数量
2. **扫码退货：** 打印委外退货单，PDA选择"委外退货"功能，扫码完成后生成委外入库单（红字）
3. **回传U9：** **仓储管理->入库->委外入库单（红字）** 模块，选择对应单据，点击"插入U9"

## 四、WMS生产业务操作流程

### 4.1 流程总览

```
ERP生产订单 -> 排产(展算) -> 生产开工 -> 材料出库(叫料/AGV送料) -> 生产投料 -> 报工 -> 成品入库
```

### 4.2 接收ERP生产订单

在ERP生产模块创建生产订单，下发至WMS，形成WMS生产订单。

### 4.3 生产订单排产

#### 4.3.1 生产订单U9下发

- U9中新增生产订单，审核后系统将自动同步至WMS
- **标准工单：** 直接被生产指令参照
- **非标准工单：** 需由工艺人员维护非标准工单工艺路径后，在生产订单界面重新绑定工艺路径，方可被生产指令参照

#### 4.3.2 生产指令列表

点击"参照生产订单"，然后维护拆分数量，保存并审核。

#### 4.3.3 生产指令明细

选择拆分后的任务，点击"展算"按钮。

#### 4.3.4 生产任务单

展算后系统自动生成生产任务单。

### 4.4 生产开工

#### 4.4.1 装配线开工

装配线生产任务单生成后自动同步至中间表，产线MES获取生产任务后点击开工，更新任务状态"生产中"至中间表，MOM自动获取生产状态。

#### 4.4.2 定子线开工

产线准备开工生产时，在工位机生产界面扫描生产任务单，即表示任务开工：
- 生产任务状态更新
- 生成对应"进行中"的生产记录单
- **注意：** 定子线扫描开工需在产线开始生产之前进行，以保证数据准确性

### 4.5 材料出库

#### 4.5.1 生产批量叫料

产线开始生产后，生产人员手持PDA选择"批量叫料"功能，扫描生产任务单，点击完成后自动生成该生产任务所需物料的库位调整单，发送给WCS调用AGV小车，将物料从物料区运送到线边区。

#### 4.5.2 生产单独叫料

若需单独叫料，生产人员手持PDA选择"单独叫料"功能：
1. 扫描生产任务单
2. 再扫描线边库位
3. 点击完成后自动生成所扫描线边库位对应工序物料的库位调整单
4. 发送给WCS调用AGV小车运送

### 4.6 生产投料

#### 4.6.1 原生产投料方式

生产人员手持PDA选择"生产上料"功能：
1. 选择对应仓库（原材料仓）
2. 扫描线边待投料条码
3. 再扫描料仓库位码
4. 点击完成，将投料仓工站号信息发送至产线MES，控制料仓开启
5. PC端生成上料类型库位调整单

#### 4.6.2 新生产投料方式

生产人员手持PDA选择"生产上料（新）"功能：
1. 选择对应仓库（原材料仓）
2. 扫描线边待投料条码，带出该物料最小包装
3. 若本次所投数量为最小包装，无需修改；若不是，可手工修改
4. 点击"拆码"，系统自动根据最小包装拆出投料条码
5. 扫描料仓库位码
6. 点击完成，将投料仓工站号信息发送至产线MES，控制料仓开启
7. PC端生成上料类型库位调整单（条码为拆出的最小包装条码）

### 4.7 生产报工

点击"生产"，扫描（或复制）任务单条码，回车后输入报工数量，点击"报工"按钮。

### 4.8 生产退料

#### 4.8.1 退料打码

生产完成后未用完的料进行退料（需在不良品数据盘点完成后进行）：
1. **仓储管理->入库->生产退料**，选择当前生产任务单
2. 勾选需退料的物料
3. 将清理出的实物放于称重秤上，光标置于"重量字段"，系统自动获取其重量
4. 根据物料单个重量计算出物料个数
5. 保存后点击生成条码，根据数据和包装规格生成条码

#### 4.8.2 退料入库

退料条码生成后进行入库操作：
- 退料人员手持PDA选择"材料退料"功能
- 扫码退料条码，再扫描退回的库位
- 若需AGV搬运，退回分拨墙库位；若无需AGV，直接退回原材料库位
- 扫码完成后点击完成，PC端生成库位调整单

### 4.9 成品入库

#### 4.9.1 扫码入库

仓库人员手持PDA选择"成品入库"功能，扫描成品条码，点击完成，PC端自动生成成品入库单。

#### 4.9.2 MOM-U9中间表

审核后系统自动插入U9中间表，5分钟后自动同步U9。可在 **仓储管理->入库->成品入库单** 模块手动点击"插入U9"。

### 4.10 生产材料倒冲

产线生产完成后，根据完工入库数量以及该产品BOM进行材料耗用计算。
- MOM成品入库后材料倒冲计算生成材料出库单
- 审核后自动生成材料出库--U9材料出库单

### 4.11 领料申请出库

适用于非生产类的领料流程（如研发领料、调机领料）：

1. **接收ERP领料申请单：** U9创建领料申请单，下发WMS生成 **仓储管理->出库->U9领料申请单**
2. **PDA扫码出库：** 仓库人员打印领料申请单，手持PDA扫描单据，再扫描出库条码，点击完成，生成PC端 **仓储管理->出库->材料出库单**
3. **MOM-U9中间表：** 审核后自动插入U9中间表，5分钟后自动同步U9

## 五、WMS销售业务流程

### 5.1 流程总览

```
销售发货 -> ERP出货计划 -> 发货通知单打印 -> PDA扫码出库 -> 回传ERP
销售退货 -> ERP退货处理 -> 退货单打印 -> PDA扫码退货 -> 回传ERP
```

### 5.2 销售发货

1. **ERP创建出货计划**
2. **发货通知单打印：** 点击"发货单打印"按钮进行打印
3. **PDA扫码出库：** PDA选择"销售出库"模块，先扫描发货通知单，再扫描实物成品条码进行出库
4. **出库完成：** 扫码完成后在PC端生成 **仓储管理->销售->销售出库单**
5. **回传ERP：** 审核后自动插入U9中间表，5分钟后自动同步U9

### 5.3 销售退货

1. **ERP创建销售退货单：** ERP创建退货处理，下发至WMS **仓储管理->销售->销售退货单**
2. **销售退货单打印：** 点击"打印"按钮
3. **PDA扫码退货：** 仓库人员手持PDA选择"销售退货"功能，扫描销售退货单，再扫描退货条码，点击完成，PC端生成 **仓储管理->销售->销售出库单（红字）**
4. **回传ERP：** 审核后自动插入U9中间表，5分钟后自动同步U9

## 十、新增需求功能

### 10.1 上料拆包

- 登录PDA，选择"生产上料"功能
- 扫描主条码与辅条码
- 扫描条码时根据条码查询物料最小包装并显示（可手动修改最新包装数）
- 扫描完成后点击"+"选择"完成"
- 根据最新包装拆码并生成货位调整单

### 10.2 条码并箱

- 登录PDA，选择"条码合并"功能
- 扫描主条码与辅条码
- 扫描主条码时点击"是否主条码"选择"是"
- 扫描完成后点击"+"选择"完成"
- 自动生成所有辅条码的其他出库单，以及主条码的其他入库单（入库数量为辅条码数量之和）

### 10.3 维修调试物料出库

- 点击参照设备维修单选择维修单
- 点击保存后生成维修备件领用
- 审核后下发至智能货柜

### 10.4 维保调试物料出库

- 点击参照设备保养单选择保养单
- 点击保存后生成保养备件领用
- 审核后下发至智能货柜

### 10.5 定子线不良出库

- 定子线生产任务完工或强制完工后，系统根据生产工序生成对应的S01（NG）盘点单
- 生产人员盘点实际NG数后填写
- 点击确认后生成材料出库单

### 10.6 GP12检验

GP12是一种特殊的成品检验流程：

1. **GP12标识：** 由质量在物料档案上维护GP12字段，后续带入至生产指令单。生产指令单GP字段可编辑，默认带出物料档案维护信息

2. **卡控规则：** GP12选择"是"时生成的任务单条码打上标记，此标记条码不可做成品入库单，物料由人员手动搬运放到GP12货位然后检测

3. **检验流程：**
   - 生产任务单自动报工完成后，系统自动生成GP12检验单
   - GP12完成后由检验人员填写GP12检验单：检验项目、合格数、不合格数
   - 不合格数自动拆码（优先尾箱拆码）

4. **入库分流：**
   - 合格数做成品入库单入成品库
   - 不合格数做成品入库单入成品不良待处理库

5. **类型区分：** GP12拆码时自动对应GP12类型，在条码档案里做区分

6. **报表：** 检验信息生成相应报表供查询

### 10.7 定子线扣料

- 定子线报工时，根据生产任务单开始时间到报工时间获取该时间段的产线设备数据
- 根据BOM生成定子线扣料
- 审核后自动生成材料出库单

### 10.8 过程不良品检验

- 登录PDA，选择"制程取样"功能，扫描线边货位
- 根据工序货位对照表和当前生产的任务单生成制程取样条码
- 检验操作与来料检验一致：
  1. 先维护制程检验方案和策略
  2. 在检验记录单中选择制程取样条码
  3. 维护检验数据

### 10.9 装配线缺料信号

- 产线MES提供缺料状态
- 根据缺料状态盘点当前生产任务单是否需要继续叫料
- 如需要，自动生成货位调整单并下发给AGV
- AGV自动搬料后返回货位调整单的物料原始货位信息和条码信息

### 10.10 三坐标对接

1. 质检在检验方案中上传三坐标文件
2. 三坐标检验时，根据物料获取最新版本的检验方案中的三坐标文件
3. 三坐标检验完成后提交数据到中间表
4. MOM根据物料、项目、工具自动同步数据到检验记录单

### 10.11 物料形态转换插入U9

审核后系统自动插入U9中间表，5分钟后自动同步U9。异常情况可以点击"插入U9"按钮。
